# Synthetic data

Generated by `scripts/generate-data.mjs` with a fixed seed, so every run writes the same files. The firm (Northwind Financial), people, and beneficiaries are fictional.

| File | Rows | What it is |
| --- | --- | --- |
| `controls.csv` | 25 | Control library: 8 automated monthly, 17 sampled quarterly |
| `control_owners.csv` | 5 | First-line owners |
| `terminations.csv` | 75 | HR terminations in 2026 |
| `user_access.csv` | 2,839 | Entitlements across seven systems |
| `wire_payments.csv` | 14,330 | Outbound wires, January–October 2026, in four feed batches a month |
| `loan_files.csv` | 3,000 | Funded commercial loans |
| `change_tickets.csv` | 1,852 | Production changes |
| `work_items.csv` | 20 | Intake backlog |

## Planted stories

1. **Orphaned access.** About one in seven entitlements of terminated employees is never revoked (AC-01).
2. **Self-approved wires.** About 1.2% of wires over the initiator's limit list the initiator as an approver (PY-02).
3. **Feed defect.** In August 2026, batch `WIRE-202608-03` drops `approver_2` on 90% of its wires. PY-01 jumps from 5 exceptions in July to 92 in August (about 18x); 91 come from that batch.
4. **Duplicate tickets.** WI-0101, WI-0102, and WI-0103 describe the same August spike; WI-0104, WI-0105, and WI-0118 the same orphaned-access pattern.

All results are on this synthetic data set only.
